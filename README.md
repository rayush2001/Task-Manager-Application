# Task Manager API

A simple task management REST API built with Python, FastAPI, and PostgreSQL.

Users can register, log in, and manage their personal tasks. The API supports creating, viewing, updating, and deleting tasks, as well as viewing completed and pending tasks.

## Features

- User registration and login
- Secure password hashing
- Cookie-based authentication
- Create, read, update, and delete tasks (CRUD)
- View all tasks, completed tasks, and pending tasks
- User-specific task management
- Interactive API documentation with Swagger UI

## Technologies Used

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT authentication
- PyJWT
